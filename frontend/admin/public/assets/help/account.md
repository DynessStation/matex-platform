# Akun Saya

> **Untuk apa:** halaman profil pribadi (belum berfungsi pada versi 1.0.10).
> **Izin yang dibutuhkan:** tidak ada.
> **Perlu diperhatikan:** jangan dipakai untuk mengubah data atau kata sandi; hubungi admin berwenang.

## Gambaran Umum

Menu **Akun Saya** dapat dibuka melalui menu profil pada bagian kanan atas **Header**. Menu ini tidak tampil pada Sidebar.

Nama pengguna dan profil akses yang sedang digunakan ditampilkan pada Header berdasarkan data akun yang login. Pengelolaan data akun administrator, termasuk penentuan profil akses, jabatan, dan kantor, dilakukan melalui halaman **Akun Admin** oleh pengguna yang berwenang.

URL: https://internal.matexindo.com/account

## Ketentuan pada Versi 1.0.10

Halaman **Akun Saya** pada versi 1.0.10 masih menggunakan tampilan bawaan kerangka aplikasi yang belum disesuaikan dengan kebutuhan MATEX. Tombol **Simpan** pada halaman tersebut belum menjalankan penyimpanan data profil maupun kata sandi. Halaman ini hanya memiliki dua tab, yaitu Pengaturan Profil dan Ubah Kata Sandi.

Oleh karena itu, pengguna tidak disarankan mengandalkan halaman ini untuk mengubah data akun. Apabila diperlukan perubahan data atau kata sandi, hubungi administrator yang berwenang atau pengembang. Penyempurnaan halaman ini dapat dipertimbangkan pada versi berikutnya.

**Kendala yang diketahui (diperbaiki pada versi 1.1):** halaman Akun Saya belum menampilkan peringatan bahwa tombol Simpan tidak berfungsi, sehingga dapat terkesan perubahan sudah tersimpan. Perubahan data akun tetap dilakukan melalui admin berwenang.
